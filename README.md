## Attribution and boundaries

The supplied research-team manuscript describes the existing discourse-structured assessment pipeline, expert-reference annotations, rubric and worksheet. These are **existing team work**, not independently built or validated by this workstream. The workstream proposes how to represent such outputs for learners and instructors. No redesigned interface has yet been shown to improve comprehension, learning or clinical performance. No user testing is documented in this folder.

## Privacy and reuse

The repository is public. Do **not** upload raw consultant workbooks, identifiable recordings/transcripts, session IDs linked to people, patient data, restricted manuscript PDFs or unpublished figures without explicit authorisation. Publish only permission-cleared, de-identified summaries and original design documentation. Bibliographic links are preferable to copyrighted PDFs.
