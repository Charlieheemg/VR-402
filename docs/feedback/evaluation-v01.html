C1. Frozen implementation

Source, dependencies and reproduction commands accompany the unchanged generator. A SHA-256 digest identifies the exact version; the reproduction harness and synthetic tests are separate files. No defect was silently repaired in the evaluated baseline.

The generator extracts populated recognised-category cells with workbook/sheet/cell pointers, original annotation text and adjacent dialogue. It builds learner and instructor drafts using fixed targets and repeated reflection/practice prompts, and produces source-record JSON and a pending audit template. Local generation is implemented. Individual routing, episode-specific actions and substantive instructor synthesis are not.

The optional external API branch was inspected but not executed. It requires explicit opt-in, sends at most 30 records and uses a configurable model identifier whose availability was not established. Local-mode evidence cannot validate that branch.

Appendix D presents a redacted, author-supplied output pair and inspects its structure and repeated prompts. That inspection is separate from this reproduction protocol and adds no workbook reruns or human-outcome evidence.

C2. Reproduction protocol and units

  1. Extract the supplied archive privately. Freeze the generator bytes and retain private input hashes. Never publish source workbooks or draft reports containing transcript excerpts.
  2. Run extraction over one AI workbook and twenty consultant workbooks, comprising ten CT and ten NN files. The consultant sources cover ten paired sessions; the AI source is not assumed to match any consultant session.
  3. Independently count nonempty cells under an explicit header lookup in row one, without calling the generator’s normalisation function. Compare totals and original cell text. Both methods retain the same header-row/layout assumption.
  4. Generate report pairs for the AI workbook and one CT/NN pair, using two examples per competency. Check displayed source pointers, exact annotation strings and all seven headings. Repeat report generation byte-for-byte and extracted-record serialisation.
  5. Run five synthetic regressions: extraction/attribution, colour handling, header alias failure, display cap/repeatability and API-mode rejection without the external-data flag. The fixtures contain invented observations only.

Units: a populated annotation cell is an extraction record, not a distinct communication event. Workbooks, paired sessions, report pairs and test cases have different denominators. No event agreement, clinical accuracy, inter-rater reliability, teaching priority or learner gain is estimated.

The portable reproduction harness replaces the supplied evaluation scripts’ absolute filesystem assumptions. This rerun independently confirms the packaged numerical totals rather than treating a conversation summary as test evidence. Environment: Python 3.12.4, openpyxl 3.1.2. Machine-readable aggregates and generator hash exclude source quotations and session filenames; input hashes and generated drafts remain private.

C4. Findings, validity limits and next iteration

The implemented structure exposes a gap between educational intent and operational behaviour. Fixed targets supply a provisional standard; copied annotations supply observations; repeated reflection and practice prompts provide the form of feedback without demonstrating case-specific feed-forward. This interpretation follows the design constructs in Hattie and Timperley and Nicol and Macfarlane-Dick; it is a developer review rather than independent educator ratings.

Exact annotation preservation is a narrow fidelity result. A context window of two rows either side, with at most six entries shown, can miss the request, acknowledgement, completion or subsequent repair. Individual attribution is explicitly unverified. Source agreement and clinical appropriateness therefore need full-event review. The original rubric, assessments and prior study results remain the upstream research team’s work.

  1. v0.2 correctness gate: validate required headers and unsupported layouts; configure source-confirmed colour maps; report extracted/displayed/omitted counts; close workbook handles. Repeat frozen inputs and synthetic cases, and publish changes and regressions rather than overwrite this baseline.
  2. Verified-output gate: obtain complete event spans and role provenance; inspect 2–3 positive, negative and ambiguous episodes claim by claim. Log category, polarity, attribution, context, additions, reviewer decisions and revisions. Separate review of clarity, relevance, specificity, actionability and clinical appropriateness from source fidelity.
  3. Educational pilot gate: after source and clinical review, compare generic and theory-guided outputs from identical evidence. Evaluate learner comprehension and corrective learning plans separately from instructor debrief accuracy, usefulness, quality and preparation time. Prespecify anchors, counterbalance cases, blind ratings where feasible and justify sample size from feasibility findings.

Subsequent simulation communication is a later outcome. The candidate balance rate B = (G − R)/(G + R) is undefined at G + R = 0 and depends on event definitions, annotation practice, team dependence and comparable behavioural opportunities. Immediate comprehension or later VR improvement cannot establish retention, workplace transfer or patient benefit. Appendix B retains the conceptual evaluation framework.
